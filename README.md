# Birthday Surprise Scrapbook Website 🎂✨

An interactive digital birthday card & surprise scrapbook website with retro blue gingham aesthetic, polaroid photo memories, sound effects, and romantic music box.

## Features
- **Storybook Surprise**: Step-by-step interactive card journey matching scrapbook aesthetic
- **Real Photo Memories**: Photobooth strips, polaroid frames, and interactive memories gallery
- **Sound & Music**: Web Audio API romantic music box loop and retro SFX (pops, chimes, camera clicks)
- **Zero Dependencies**: Pure HTML5, CSS3, and modern JavaScript
